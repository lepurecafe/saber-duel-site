앱에서 처리하는 정보

Saber Duel은 계정 가입이나 광고 없이 사용할 수 있습니다. 사용성 분석 기능이 포함된 버전은 동의한 경우에만 제한된 분석 정보를 보냅니다. 이 기능이 없는 이전 버전은 사용성 분석 정보를 보내지 않습니다. 가까운 상대와의 대결은 분석 서버와 무관하게 작동합니다.

모션과 기기 간 연결

iPhone의 모션 센서 데이터는 기기에서 처리하여 스윙, 소리, 햅틱 및 격돌을 구현합니다. 주변 상대와 대결할 때는 임시 연결 식별자, 검의 켜짐 상태, 격돌 강도와 타이밍, 연결 유지 정보 및 지원 기기의 근거리 측정 토큰과 기능 정보를 기기 간에 교환합니다. 거리 측정값은 기기에서 처리됩니다.

통신 보호

연결 이후 게임 메시지는 세션별 키로 암호화됩니다. 주변 기기를 찾기 위한 서비스 광고와 최초 키 교환 정보는 이 암호화에 포함되지 않습니다. 자동 연결은 상대 사용자의 실제 신원을 확인하는 기능이 아닙니다.

기기에 저장되는 정보

선택한 손잡이와 최초 사용 안내 완료 여부는 기기에 저장됩니다. 앱 자체는 플레이 기록이나 원시 모션 데이터를 지속적으로 저장하지 않습니다. 앱을 삭제하면 앱의 로컬 데이터가 제거됩니다. Apple 백업에서 복원되는 데이터는 사용자의 백업 설정에 따릅니다.

접근 권한

로컬 네트워크 접근은 주변 상대를 찾고 연결하는 데 사용합니다. 지원 기기에서는 Nearby Interaction을 이용해 상대 기기와의 거리를 측정합니다. 앱은 GPS 위치, 카메라, 마이크, 연락처 또는 사진 보관함을 사용하지 않습니다. 접근 권한은 iPhone 설정에서 변경할 수 있으며, 제한하면 관련 연결 기능이 작동하지 않을 수 있습니다.

웹사이트와 Apple 서비스

이 웹사이트에는 자체 분석 도구나 광고, 추적 쿠키를 추가하지 않았습니다. 호스팅 제공자인 GitHub Pages는 보안 목적으로 방문자의 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요. App Store, TestFlight 및 Apple 진단 정보는 Apple 정책과 사용자 설정에 따릅니다.

지원 문의와 삭제 요청

이메일로 문의하면 이메일 주소와 사용자가 직접 포함한 내용을 문의 대응 목적으로 처리합니다. 문의 대응에 필요한 동안 보관하며, 관련 정보의 열람·정정·삭제 요청은 아래 연락처로 보내주세요. 비밀번호 등 민감한 정보는 보내지 마세요.

사용성 분석

동의하면 설치별 임의 식별자로 사용 세션과 재방문을 연결합니다. 이벤트 발생 시각, 세션 식별자, 점화 횟수, 손잡이 선택, 연결 시도·결과, 경과 시간, 앱 버전·빌드, 언어 및 테스트/운영 구분을 이벤트 전송 시 HTTPS로 미국의 PostHog, Inc.에 보냅니다. 이는 가명 데이터이며 완전한 익명 데이터가 아닙니다. 이름·이메일, 원시 모션, 상대 식별자, 정확한 위치, 화면 녹화는 보내지 않습니다. 분석 SDK나 자동 터치 수집 없이 이벤트 API를 직접 사용합니다. 통신 과정에서 IP 주소는 서버에 보일 수 있으나, 프로젝트에서는 이벤트의 클라이언트 IP 폐기와 GeoIP 정보 추가 생략을 적용합니다.

보관·삭제

공유는 동의 전까지 꺼져 있고, 동의하지 않아도 모든 플레이 기능을 사용할 수 있습니다. 앱 정보에서 공유를 끄면 전송을 취소하고 기기의 대기 이벤트를 삭제합니다. 이미 PostHog에 도착한 데이터까지 회수하지는 못합니다. 대기열은 메모리에만 최대 100개 저장하며 24시간이 지난 이벤트는 폐기하고 앱 프로세스 종료 시 사라집니다. 임의 식별자와 동의 상태는 앱 데이터가 제거될 때까지 기기에 남습니다. 현재 PostHog 무료 플랜의 분석 데이터 보관 기간은 1년이며, 90일 자동 삭제는 설정되어 있지 않습니다. 이미 전송한 데이터의 삭제는 앱 정보의 분석 ID를 music.bk@gmail.com으로 보내 요청할 수 있습니다. 앱 삭제 전에 요청하면 식별에 도움이 됩니다. 백업과 PostHog 서비스·보안 기록에는 각 제공자의 정책이 적용됩니다.
