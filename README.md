# Saber Duel website

Public Korean and English introduction, support, and privacy pages. The iPhone application source lives in a separate private repository.

Serve locally: `python3 -m http.server 8768`. No dependencies, build step, JavaScript, external fonts, or analytics.

GitHub Pages publishes the main branch root. Korean: `/`; English: `/en/`. Each language has `privacy/` and `support/` pages.

Existing app icon and industrial hilt artwork are used with the project owner’s authorization. Website assets are not licensed for reuse. App development credits: Bongkwon Choi (BK), with original prototype contributions by junghanKang (Karl).
